# בוט WhatsApp – האקדמיה לטניס גלי הדר

נציג שירות דיגיטלי ב-WhatsApp: עונה ללקוחות, ממליץ על מסגרת, אוסף פרטי הרשמה (לידים)
ומעביר אותם למנהל. בנוסף משמש את הצוות לדיווח נוכחות וניהול רשימות מתאמנים.

## איך זה עובד

```
Whapi → POST /webhook?token=... → controllers/webhookController.js
  ├─ שיחה שאינה פרטית (קבוצה / ערוץ / סטטוס) → מתעלמים
  ├─ הודעה שהצוות שלח ידנית → הבוט שותק מול הלקוח (HANDOFF_PAUSE_HOURS)
  ├─ מנהל / מאמן → נוכחות וניהול רשימות (services/attendanceService.js)
  └─ לקוח → "איך שמעתם עלינו?"
        ├─ MOVE / עמית / FreeFit → מסלול מיוחד → ליד למנהל
        └─ רגיל → services/messageRouter.js
              ליד / המלצה / FAQ / ציוד → OpenAI (רק כמוצא אחרון)
```

| תיקייה | תוכן |
|---|---|
| `controllers/` | קבלת ההודעות וניתוב |
| `services/` | לוגיקת שיחה, לידים, נוכחות, חיבור ל-WhatsApp ו-OpenAI |
| `knowledge/` | מידע עסקי: מחירים, סניפים, אימוני ניסיון — **מקום אחד לעדכן** |
| `prompts/` | הנחיות ל-OpenAI ונוסחי השאלות של הבוט (`questionTexts.js`) |
| `utils/` | זיהוי טקסט, מזהי WhatsApp, פענוח פקודות צוות |
| `test/` | בדיקות אוטומטיות |

## התקנה והרצה

```bash
npm install
cp .env.example .env   # ומלאו את הערכים
npm start
```

השרת יוצר את טבלאות מסד הנתונים בעצמו בעלייה.

### הגדרת Whapi
כתובת ה-Webhook: `https://<השרת>/webhook?token=<WEBHOOK_SECRET>`  
כדי שההעברה לנציג אנושי תעבוד, יש לאפשר ב-Whapi גם שליחה של הודעות יוצאות (from_me).

### בדיקת תקינות
`GET /health` — מחזיר 200 כשהשרת ומסד הנתונים תקינים.

## בדיקות

```bash
npm test
```

הבדיקות לא צריכות מסד נתונים, WhatsApp או OpenAI — הם מוחלפים בגרסאות מדומות
(`test/helpers/harness.js`). הבדיקות רצות אוטומטית ב-GitHub בכל העלאה.

## לידים

- ליד נשלח למנהל כשיש: שם, גיל, סניף, טלפון ומטרת פנייה (נקבעת אוטומטית).
- כל ליד נשמר בטבלת `leads`. אם השליחה נכשלה, השרת מנסה שוב כל 5 דקות.
- לקוח שכבר נשלח עליו ליד יכול לכתוב "מתאמן נוסף" כדי לרשום ילד נוסף.

## פקודות צוות (ב-WhatsApp)

| פקודה | מי |
|---|---|
| `נוכחות צעירה שלישי` + שמות בשורות | מאמנים ומנהלים |
| `נוכחות צעירה אתמול` + שמות | מאמנים ומנהלים |
| `תוסיף את דני לוי לצעירה` / `תוריד ...` / `תעביר ... מ... ל...` | מנהלים |
| `תראה לי את הרשימה של קבוצה א+ד 16:00` | מנהלים |
| `עצור בוט 0501234567` / `הפעל בוט 0501234567` | מנהלים |
| `בדיקת מנהל` | מנהלים |

שינויי רשימות של הנבחרות ושל מפגשי גלי הדר נשמרים בטבלה שממנה נבנית הנוכחות,
ולא נדרסים בהפעלה מחדש.
